## Mokymosi programos aktualumas

Dirbtinis intelektas keičia programuotojo darbą: didelę dalį įprasto kodo šiandien parašo DI asistentai, o darbdaviai vis dažniau ieško žmonių, kurie moka su jais dirbti, kritiškai vertinti jų sukurtą kodą ir į programas integruoti DI funkcijas – pokalbių asistentus, paiešką organizacijos dokumentuose, DI agentus, atliekančius užduotis savarankiškai.

Dauguma pradedantiesiems skirtų programavimo kursų moko tik tradicinio žiniatinklio programavimo, o DI programos skirtos įrankių naudotojams, ne kūrėjams. Ši programa sujungia abi sritis: dalyviai išmoksta žiniatinklio programavimo pagrindų (HTML, CSS, JavaScript, React, Next.js), dirba su DI programavimo asistentais ir išmoksta į savo programas integruoti didžiuosius kalbos modelius bei kurti paprastus DI agentus.

Skaitmeninė kompetencija yra pirmoji prioritetinė IMP sistemos finansavimo sritis, o DI ir darbo ateitis – viena pagrindinių 2026 m. Kursuok konferencijos temų. Programa skirta tiek norintiems pradėti karjerą IT srityje, tiek kitų sričių specialistams, kurie nori patys kurti DI sprendimus savo organizacijai.

## Tikslas ir uždaviniai

**Tikslas** – suteikti dalyviams žiniatinklio programavimo pagrindų ir praktinių įgūdžių kurti bei talpinti internete žiniatinklio programas su dirbtinio intelekto funkcijomis ir DI agentais.

**Uždaviniai:**
1. Išmokyti kurti prisitaikančias, neįgaliesiems pritaikytas žiniatinklio sąsajas naudojant HTML, CSS ir JavaScript.
2. Išmokyti kurti žiniatinklio programas su React ir Next.js.
3. Išmokyti programuoti naudojant DI programavimo asistentus ir kritiškai vertinti jų sukurtą kodą.
4. Išmokyti integruoti didžiųjų kalbos modelių API į žiniatinklio programas.
5. Išmokyti kurti DI funkcijas ir paprastus DI agentus, kurie naudoja įrankius ir organizacijos duomenis.
6. Išmokyti saugiai talpinti programas internete ir dirbti komandoje naudojant Git ir GitHub.

## Mokymosi programos anotacija

108 ak. val. trukmės nuotolinė programa pradedantiesiems, norintiems išmokti kurti žiniatinklio programas su dirbtinio intelekto funkcijomis. Dalyviai išmoks HTML, CSS ir JavaScript pagrindus, kurs programas su React ir Next.js, programuos kartu su DI asistentais, integruos didžiųjų kalbos modelių API, kurs pokalbių asistentus, paiešką dokumentuose ir paprastus DI agentus bei talpins programas internete. Programa baigiama komandiniu projektu – internete veikiančia programa su DI funkcija, sukurta naudojant GitHub. Baigus programą išduodamas pažymėjimas.

## Mokymosi programos anotacija anglų kalba

A 108-academic-hour live online programme for beginners who want to build web applications with AI features. Participants learn HTML, CSS and JavaScript fundamentals, build applications with React and Next.js, code alongside AI assistants, integrate large language model APIs, build chat assistants, document search and simple AI agents, and deploy their applications online. The programme ends with a team project: a live web application with an AI feature, built using GitHub. A certificate is issued on completion.
